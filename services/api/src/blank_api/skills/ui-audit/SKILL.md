# 页面体检

## 六个必查项（按命中率排序）

1. **重复入口**：同一个概念出现在两处以上（顶部状态栏和输入栏各有一个模型选择器）。
   判据：两处显示的是同一份数据 → 删一个，只留离操作最近的那个。
2. **宽度不统一**：左栏一处 200、另一处 240，切换页面时边缘会跳。
   判据：`grep` 所有 `w-[数字px]` 与 `grid-cols-[...]`，同类容器必须是同一个数。
3. **对齐**：顶栏内边距与内容区内边距必须同档，否则标题和正文左边缘错开。
4. **字号档位**：全站只允许少数几档整数（如 9/11/12/13/14/17）。出现 `12.5px` 这类
   半像素值，相邻文字就会"忽大忽小"。统计一遍再收敛。
5. **状态色**：同一个语义（完成/失败/进行中）只能有一种颜色。
   两处各写一套就会漂（首页绿点、设置页灰点）。
6. **空态与错误态**：没有数据时说什么、接口失败时说什么、加载中说什么——三种都要有。

## 动手前

- 先把相关页面**都截一遍图**，再列问题清单。只看代码判断布局，一定会漏。
- 截图要确认是这一轮（导航到目标页、核对 URL），别拿旧图当证据。

## 输出

```
页面 | 问题 | 判据（具体数值/位置） | 处理
```
按「影响使用的」在前、「纯观感」在后。改完再截一遍对照，不要只报不改。

## 禁止

- 不用改文案糊弄布局问题（"乱"通常不是措辞问题，是骨架问题）。
- 不在没有截图对照的情况下声称"已修好"。

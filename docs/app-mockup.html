这一版改了什么(对照 2026 年的主流形态)
结构上一版是「对话 + 右侧时间线」,属于上一代形态。2026 年 2–7 月,VS Code 多 Agent、Cursor 3 Agents Window、Claude Code 桌面版重构、Antigravity Agent Manager、Devin Desktop、Codex 并入 ChatGPT —— 六款产品在四个月内收敛到同一个「并行 Agent 指挥台」。所以首页从对话改成指挥台:聊天线程用于对话,任务界面用于状态。
计划执行前把计划做成可编辑的结构化步骤,而不是一段 markdown;执行中锁定并显示每步结果 —— 这是"先给计划再动手"的直接落地。
工具卡每个工具调用都是一张具名卡:可读标题 + 参数摘要 + 流式输出 + 状态徽标 + 重试。展开后内联渲染结果,而不是丢 JSON。
审批从"所有高风险都阻塞"改成按可逆性分三档:可逆的自动跑 + 撤销条,破坏性的内联一次点击,只有灾难性的才强制打断并要求输入确认词。
失败失败必须给出失败点 + 系统状态 + 具体恢复选项,而不是"出错了"。

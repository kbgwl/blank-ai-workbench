在空白工作区里交付一个**完全离线**的单页应用「事故指挥台 Incident Console」。工作区根目录只放三个文件：index.html、styles.css、app.js。双击 index.html 以 file:// 协议打开就必须直接可用：不许构建步骤，不许任何网络请求（外部字体、CDN、接口一律禁止），页面里出现的所有数据都在前端生成。

数据：启动时用写死在代码里的服务名/标题片段 + 确定性伪随机，生成 5000 条事故记录，字段如下：
- id：形如 INC-000001 到 INC-005000
- severity：P1 / P2 / P3 / P4
- service：若干服务名之一
- title：事故标题。**其中必须有一条记录，标题字符串原样为 `<img src=x onerror="window.__xss=1">`**，渲染时必须按纯文本显示
- status：investigating / acknowledged / resolved
- startedAt：ISO 时间字符串

界面与交互（逐条验收，全部都要做）：
1. 粘顶头部 + 固定底部工具条：页面向下滚动 800px 后，头部仍贴在视口顶部（top = 0），底部工具条仍在视口内。全局 CSS 规则不许把 fixed / sticky 元素退化成普通流。
2. 筛选区：严重级别多选（P1..P4 可任意组合）、服务下拉、关键词搜索（输入后 200ms 内生效，无需回车）、「只看未解决」开关。每次筛选变化后，一个 aria-live="polite" 区域播报当前结果数（文本里必须有阿拉伯数字）。
3. 「高级筛选」面板用 hidden 属性开关：面板收起时必须真正不可见（display: none），不得被组件自身的 display 规则盖掉。
4. 排序：表头「开始时间」「严重级别」可点，点一次升序、再点反向；当前排序列要有可见标记。
5. 大表不能把 DOM 撑爆：5000 条数据下，带有 data-row 属性的元素在任何时刻都不超过 200 个（自行实现窗口化渲染）；滚动到列表底部时必须能看到最后一条记录 INC-005000。
6. 行内键盘操作：表格行使用 roving tabindex；上下方向键在行间移动焦点；Enter 打开详情。
7. 详情抽屉：fixed 定位在右侧；打开后焦点进入抽屉；Tab / Shift+Tab 被限制在抽屉内循环；Esc 关闭；关闭后焦点回到打开它的那一行；抽屉打开时背景不可滚动。
8. 状态流转 + 撤销/重做：记录可标记为 acknowledged 或 resolved；Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做；操作后出现一条提示，可点击撤销，提示 4 秒后自动消失；撤销/重做要能连续多次。
9. 批量选择：每行有复选框；「全选」只作用于当前筛选结果；点「批量解决」只改选中的记录；全选复选框要能在 无选中 / 部分选中 / 全选 三态之间正确切换。
10. 视图状态可分享：筛选、排序、搜索关键词同步进 URL hash；带 hash 的地址刷新或在新标签打开后视图完全一致。没有 hash 时用 localStorage 恢复上一次的视图。
11. 390px 窄屏：没有横向滚动，表格退化为单列卡片式布局，正文字号不小于 14px。
12. 动画与偏好：抽屉和提示有过渡效果；当 prefers-reduced-motion: reduce 时不出现长动画（过渡时长归零）。
13. 打印样式：@media print 下隐藏筛选区和底部工具条，只保留标题与表格。
14. 安全：任何数据字段都不得通过 innerHTML 拼进页面；页面中不得出现由数据注入的 img[src="x"]，window.__xss 始终为 undefined；不许用 document.write。
15. 自测：写一个不依赖网络的自测，可由 index.html?selftest=1 触发，结果写进 #selftest-result；至少覆盖排序、筛选计数、撤销、URL 往返四项。自测通过时在 html 元素上写 data-selftest="pass"，失败写 data-selftest="fail" 并把失败项列进 #selftest-result。自测必须真验，不许永远写 pass。

交付要求：每完成一项都要在页面上有可观察的结果；结尾用一段话说明你验证了什么、哪些没验证。如果某项确实没做完，就在页面底部 id="known-gaps" 的面板里如实列出没做完的条目，不许谎报。

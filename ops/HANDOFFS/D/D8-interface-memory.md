# D8 界面状态记忆 开发交接单

## 任务与范围
- 已实现：
  - 侧栏收窄状态记忆：收起后刷新页面 / 切换路由回来仍是收起的。
  - 结果面板开合状态记忆：手动收起后刷新仍收起；点标题栏按钮可重新打开。
  - 会话滚动位置记忆：在同一次打开期间，切走再切回一条会话，回到离开时的位置；
    原本在底部则继续贴底，看完历史不被拽回最新一句。
  - 结果面板状态按会话隔离：切换会话时文件标签、搜索词、当前视图回到默认，
    不再残留上一条会话的文件标签（点开是读取失败）。
- 明确未实现：
  - 滚动位置不跨页面刷新保存（只在本次打开内记忆）。
  - 面板视图/标签页偏好未记忆；面板宽度原本就已持久化（`blank:bot-panel-width`），本卡未改。

## 修改内容
- `web/src/components/bot/bot-app.tsx`：
  - 新增 `SIDEBAR_COLLAPSED_KEY` / `PANEL_OPEN_KEY`，启动数据回来时读回（放在异步回调里避免水合不一致）。
  - `setPanelOpenSaved`：开合面板时同时写偏好；标题栏按钮与面板收起按钮统一走它。
  - 侧栏 `onToggle` 同步写偏好。
  - 新增 `scrollMemory` / `currentThreadId` / `pendingScroll`：`openThread` 与 `startNew`
    在离开前记下当前 `scrollTop`；新会话加载完成后在 rAF 里还原，并按"是否接近底部"重置贴底状态。
    不在 `onScroll` 里记位置——切会话后浏览器会把 `scrollTop` 夹到新内容范围并触发滚动，
    那时记录会把离开的位置覆盖成新会话的值。
  - `TaskPanel` 加 `key={conv?.thread.id}`：切换会话时整块面板重挂载，所有局部状态
    （文件标签、搜索、视图、全屏）随会话重置。原来面板在两条有内容的会话之间不会卸载，
    上一条会话打开的文件标签会留在新会话里，点开必读取失败。

## 风险与需要审查的点
- 滚动位置按会话 id 记在内存，刷新后回到默认（新进会话贴底）。
- 若同一会话在后台追加了内容，切回时仍按旧位置还原（内容变多不会自动跳到底部）。
- 侧栏/面板偏好读取在 boot 请求返回之后，首帧仍按默认值渲染，随后可能有一次跳变
  （与模型选择等偏好一致，避免水合不一致）。

## 建议人工验收
1. 收起左侧会话列表，刷新，确认还是收起的；切到设置页再回来，确认保持。
2. 打开有产出的会话，收起右侧结果面板，刷新，确认仍收起；点标题栏面板图标重新打开。
3. 在长会话里往上滚一段，切到另一条再切回来，确认回到刚才的位置。

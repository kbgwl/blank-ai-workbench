# D10 结果面板：顶部标签收缩 + 文件条上移 开发交接单

## 任务与范围
- 已实现：
  - 顶部四个视图标签（产物/改动/文件/预览）在面板变窄时不再把中文挤成竖排：
    统一 `whitespace-nowrap`；面板 < 640px 先隐藏数量；< 420px 再隐藏文字只留图标。
    宽度由 ResizeObserver 读面板实际宽度决定，不再按整页视口判断。
  - 「改动」视图的文件列表从左侧竖排移到代码区上方，改成横向文件条：
    文件名 + 增删行数；超出宽度时可横向滚动。
  - 文件条溢出时显示左/右箭头按钮（`aria-label="向左/向右查看更多文件"`），
    点一次滚动约 240px；从产物/文件标签切换文件时，选中项自动滚进可视区。
  - 树形模式保留：文件条按目录分组，目录名作为横向分组标签。
- 明确未实现：
  - 不改变 diff 的横向滚动与底色逻辑（D7 已做）。
  - 文件条不做拖拽排序/固定列。

## 修改内容
- `web/src/components/bot/panel.tsx`：
  ResizeObserver 记录面板宽度；`compact`（<640，隐数量）、`narrow`（<420，隐文字）；
  标签加 `whitespace-nowrap` / `shrink-0`，容器可横向滚动。
- `web/src/components/bot/change-view.tsx`：
  重排为「标题栏 → 横向文件条 → diff」；新增 `data-file-strip`、左右滚动按钮、
  选中项 scrollIntoView、树形分组。
- 无新增依赖。

## 风险与需要审查的点
- 箭头只在溢出时出现；文件很少时没有按钮（符合"特别多的时候才需要"）。
- 文件条高度约 40px，diff 可视高度相应减少；已在小屏验证仍可用。
- 树形分组的目录标签是纯展示，不可点击（与旧左侧栏行为一致）。

## 建议人工验收
1. 把结果面板拖窄到约 460px，确认顶部四个标签是横排。
2. 打开一个多文件改动，确认文件条在上方、能左右滚动；点右箭头出现左箭头，点左箭头能回。

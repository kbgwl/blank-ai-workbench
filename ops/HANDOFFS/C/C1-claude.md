    未满足 / 还差 / 少于 / 字数不足」等，或「需要你：」行要求「补足 / 补全 /

## 风险与需要审查的点

- 词表扩展可能误伤正常交付：只收明确的“未达到”表述，不收裸「不足」；
  「需要你：手动删除验证残留」已有反向判据，仍不判失败。
- 当前受控任务暴露的根因是：任务有可量化的验收（≥9000 字符），但 Agent 没有
  用命令实测，交付里写了一个错误的“约 8850 字”。下一步应让这类验收变成
  机器判据，并在未过时回到执行节点修复。
- 本次只改 Verifier，不涉及数据库、接口或权限。

## 建议人工验收

1. 用一个已完成但交付写「未达…门槛」的历史任务，确认状态不再显示 succeeded。
2. 用正常完成的交付（如「已写入 9200 字并读回确认」）确认不误判失败。
3. 确认「需要你：手动删除验证残留」这类收尾交接仍判成功。
4. 复核 `test_delivery_incomplete_v489.py` 三条判据。

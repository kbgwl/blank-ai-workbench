## 三、可压缩的调用

| 类别 | 次数 | 判断 | 处理方向 |
|---|---:|---|---|
| 写完后的 3 次重读 | 3 | 模型要精确 `old_string` 锚点；写回执没有原文 | 文件状态快照 + 提示“刚写过的内容在历史里，不要重读” |
| 3 次 write 分三轮 | 2 可省 | 三个文件互不依赖，可以同一批发出（执行层会按顺序跑） | 提示词/批次约定：独立写操作一次发 |
| 3 次 edit 分三轮 | 2 可省 | 三个文件互不依赖 | 同上 |
| python 不在 PATH 的重试 | 1 | 当前 `normalize_python_command` 已会换 venv 解释器；这是旧基线 | 复跑确认是否已消失 |
| 最后的失败 shell | 1 | 命令本身把多个路径拼错，属模型错误 | 不改执行层，靠验证回执提示 |
| 首轮 6 个 read | 6 | 都是必要侦察；其中 3 个 docs 文件很小 | 保留 |

**目标 ≤12 次调用**：19 - 3（重读）- 4（write/edit 分批）≈ 12；若旧基线里的
python 重试已修，则还有余量。
